01 the story

From curiosity to code.

My journey into technology began with a simple curiosity that grew into a deep passion for coding and design.

During my years at the University of Milan, I not only strengthened my technical knowledge but also discovered the value of collaboration and creative problem-solving.

That's what draws me to digital payments: a domain where correctness, security, and reliability aren't optional, and every detail has real consequences.

// before the code

Drawing has always been my favorite way to express ideas, long before I ever wrote a line of code. That attention to detail is what first brought me to the frontend and to digital design.

Today, as a software engineer, the same curiosity has moved deeper into the stack: I care less about how a product looks and more about how it works, how it fails, and how it holds up over time — which is why payments is where I'd like to grow next.

04 how I build

Foundations first.

// angular

Components that scale.

I build with Angular, focusing on modular architecture, predictable state management, and reusable components that stay clean even as projects grow. My goal is to create codebases that scale smoothly, remain easy to understand, and avoid unnecessary complexity over time. On the development side, I care about structure and consistency: components are designed to be flexible, maintainable, and ready to adapt to different needs without breaking the overall system. The same care goes into what sits behind the interface: clear data flow, well-defined contracts with the APIs, and explicit handling of errors and edge cases, so the application behaves predictably even when things go wrong.

// architecture

Modular architecture.

Architecture comes before features — I focus on building solid foundations with modular structures, maintainable patterns, and predictable systems that remain clear as projects grow. From frontend organization to backend integration, every layer is designed to work cohesively and evolve without introducing unnecessary complexity. I approach development with a full-picture mindset: reusable components, structured APIs, efficient data flow, and backend-aware decisions that improve stability and long-term maintainability. Performance remains a core principle, with lean bundles, optimized loading, and code that earns its place in the build.
